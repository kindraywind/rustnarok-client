// Blind overlay (issue #522). Load with @loadnpc, unload with @unloadnpcfile. Whisper
// npc:RustnarokBlind "blind", "deep", "other" or "clear". "other" blinds a Poring, not the player.
-	script	RustnarokBlind	-1,{
	end;
OnWhisperGlobal:
	if (@whispervar0$ == "blind")
		sc_start SC_BLIND, 600000, 1;
	else if (@whispervar0$ == "deep")
		sc_start SC_HANDICAPSTATE_DEEPBLIND, 600000, 1;
	else if (@whispervar0$ == "other") {
		monster "prontera", 160, 184, "BlindPoring", 1002, 1, "RustnarokBlind::OnPoring";
		sc_start SC_BLIND, 600000, 1, 10000, SCSTART_NOAVOID, $@mobid[0];
	} else if (@whispervar0$ == "clear") {
		sc_end SC_BLIND;
		sc_end SC_HANDICAPSTATE_DEEPBLIND;
		killmonster "prontera", "RustnarokBlind::OnPoring";
	}
	end;
OnPoring:
	end;
}
